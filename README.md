# alarm-app-site

Minimal static site for GitHub Pages hosting of the Alarm Clock privacy policy.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Push the contents of this folder.
3. Enable GitHub Pages from the `main` branch root.
4. Use the published URL as the `Privacy Policy URL` in App Store Connect.

Example URL:

`https://<your-github-user>.github.io/<repo-name>/`
